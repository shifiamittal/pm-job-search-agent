# Controller & QA Checklist

## A. Candidate Evidence Base Gate
- [ ] Master resume reviewed
- [ ] Supporting files reviewed
- [ ] Major projects extracted
- [ ] Metric ledger created
- [ ] Claim ledger created
- [ ] Direct vs transferable distinctions captured
- [ ] Conflicts captured
- [ ] Genuine gaps captured
- [ ] Candidate-confirmed facts separated

## B. Role Understanding Gate
- [ ] Validated shortlist v1.2 role state reused without reinterpretation
- [ ] Baseline qualifications and required/preferred distinctions preserved
- [ ] Actual job-to-be-done identified
- [ ] Responsibility clusters identified
- [ ] Hiring criteria identified
- [ ] Importance assigned
- [ ] Specialist requirements identified
- [ ] Scope / level interpreted
- [ ] Likely HM questions identified
- [ ] Uncertainties labeled

## C. Shortlist Handoff and Execution Gate
- [ ] Decision is exactly `APPLY — PRIORITY`, `APPLY`, `HOLD / INVESTIGATE`, or `DO NOT APPLY`
- [ ] Controller validation accepts an APPLY outcome before downstream eligibility
- [ ] `HOLD / INVESTIGATE` stops downstream work until resolved
- [ ] `DO NOT APPLY` stops downstream work
- [ ] Downstream execution explicitly invoked/enabled; acceptance alone is insufficient
- [ ] `capability_fit`, `domain_context_fit`, `overall_fit_assessment`, and `limitation_or_difference` preserved with criterion IDs and nulls
- [ ] Gaps, baseline qualifications, scope, and rationale preserved
- [ ] Geography, work model, relocation, and eligibility remain separate from fit

## D. Evidence Retrieval Gate
For each critical criterion:
- [ ] Source-backed evidence found
- [ ] Ownership clear
- [ ] Mechanism clear
- [ ] Impact defined correctly
- [ ] Metric population understood
- [ ] Source captured
- [ ] Confidence captured
- [ ] Conflicts captured

## E. Evidence Mapping Gate
- [ ] Strongest story selected
- [ ] Secondary story selected if useful
- [ ] Validated capability/domain mapping fields retained separately, with overall assessment and limitations
- [ ] Supplemental resume evidence does not silently change upstream classifications
- [ ] Gaps preserved
- [ ] Weak evidence not upgraded
- [ ] Differentiators identified

## F. Resume Strategy Gate
- [ ] Template chosen
- [ ] Headline strategy defined
- [ ] Summary themes defined
- [ ] Section order locked
- [ ] Bullet IDs created
- [ ] Bullet contracts created
- [ ] Priority labels assigned
- [ ] MUST_KEEP protected
- [ ] KEEP_SEPARATE protected

## G. Writing Gate
For every bullet:
- [ ] Uses approved evidence
- [ ] Preserves ownership
- [ ] Preserves metric definition
- [ ] Preserves scope
- [ ] Preserves direct / transferable status
- [ ] Supports a target criterion
- [ ] Includes impact when defensible
- [ ] Adds no unsupported technology / ownership

## H. Manifest Gate
- [ ] Headline frozen
- [ ] Summary frozen
- [ ] Section order frozen
- [ ] Bullet IDs frozen
- [ ] Bullet order frozen
- [ ] Exact bullet wording frozen
- [ ] Manifest version assigned

## I. Document Generation Gate
- [ ] Template used for formatting only
- [ ] Manifest used for content only
- [ ] No old wording copied
- [ ] No automatic shortening
- [ ] No merging / removal
- [ ] No metric edits
- [ ] No reordering

## J. Exact Content Validation Gate
- [ ] All IDs present
- [ ] All blocks exact
- [ ] No extra blocks
- [ ] No old-template leakage
- [ ] No wrong-company references

## K. Visual / Page-Space Gate
- [ ] Page count evaluated
- [ ] No clipping
- [ ] No broken bullets
- [ ] No awkward section breaks
- [ ] No excessive whitespace
- [ ] Font readable
- [ ] Important evidence prominent

Question:
> Is compression actually necessary?

## L. Compression Gate
Only if real page pressure exists:
- [ ] Core Competencies detail first
- [ ] Summary second
- [ ] Sentence tightening third
- [ ] CAN_COMBINE next
- [ ] OPTIONAL next
- [ ] MUST_KEEP / KEEP_SEPARATE only with explicit reconsideration

Any content change returns to Writing and requires a new manifest.

## M. Final QA Gate
- [ ] Correct company
- [ ] Correct role
- [ ] Correct job ID if available
- [ ] Correct headline
- [ ] All locked IDs present
- [ ] Exact content validation passed
- [ ] No unsupported claims
- [ ] No unresolved metric accidentally used
- [ ] No semantic inflation
- [ ] No template leakage
- [ ] Correct page count
- [ ] No clipping
- [ ] Formatting consistent
- [ ] Filename correct
- [ ] Latest validated version delivered
